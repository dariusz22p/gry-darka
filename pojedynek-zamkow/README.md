# ⚔️ Pojedynek Zamków

Artyleria turowa dla 2 graczy (hotseat). Ustaw kąt i moc, uwzględnij wiatr i zniszcz zamek przeciwnika.

## 🎮 Graj teraz

**[👉 ZAGRAJ](../)**

## 📖 Jak grać

- **Gracz 1** (lewa strona) — muszka + strzał
- **Gracz 2** (prawa strona) — muszka + strzał
- Ustaw **kąt** i **moc** strzału
- Pamiętaj o **wietrze**! ☁️
- Zniszcz zamek przeciwnika

## ⚙️ Mechanika

- **Wiatr** — zmienia trajektorię pocisku
- **Grawitacja** — pociski spadają naturalnie
- **Obrażenia** — im bliżej trafienia, tym więcej obrażeń
- **Tury** — gracze strzelają na zmianę

## 🕹️ Sterowanie

- **Mysz** — ustawianie kąta i mocy
- **SPACEBAR** — strzał
- **R** — restart gry

## 🏠 Powrót

- Wciśnij **ESC** lub **H** — powrót do menu głównego
