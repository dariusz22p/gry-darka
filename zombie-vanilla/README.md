# 🧟 Napór Zombie — Vanilla (Prototyp 1.0)

**Oryginalna gra** — Broń bazę przed falami zombie. To jest wersja 1.0 - prototyp, który pozostaje bez zmian jako punkt odniesienia.

## 🎮 Graj teraz

**[👉 ZAGRAJ](https://dariusz22p.github.io/gry-darka/zombie-vanilla/)**

## 📖 Jak grać

Jesteś dowódcą zespołu. Twoim zadaniem jest:
- **Obrona** — Broń bazę przed falami zombie
- **Kierowanie** — Poruszaj ekipą w górę i w dół
- **Atak** — Zespół strzela automatycznie (zawsze w lewo)
- **Rekrutacja** — Dobieraj nowych ludzi (LUDZIE panel)
- **Ulepszenia** — Zwiększaj moc i szybkostrzelność (MOC panel)
- **Bomby** — Używaj specjalnych broni

## 🎯 Fale & Zombies

- **20 fal** w grze
- **Trudność rośnie** — każda fala jest trudniejsza
- **Kolory zombie** — zmienne co 5 fal (zielone → czerwone)
- **Mini-bossy** — co 12 spawów zombie (od fali 3)
- **Loot** — bossy dają bonusy (bomby, ludzie, moce)

## ⌨️ Sterowanie

- **↑ / W** — ruch ekipy w górę
- **↓ / S** — ruch ekipy w dół
- **SPACEBAR** — bomba zwykła (50% closest zombie)
- **N** — bomba atomowa (100% wszystkie, kosztuje 2 bomby)
- **P** — pauza
- **F** — pełny ekran
- **R** — restart
- **M** — wyciszenie
- **ESC / H** — powrót do menu

## 💡 Porady

- **Upgrade moc wcześnie** — zadawanie więcej obrażeń ratuje bazę
- **Rekrutuj strategicznie** — więcej ludzi = wyższa szybkostrzelność
- **Bomby ratują** — zaoszczędzaj je na trudne momenty
- **Easy mode** — świetny do nauki
- **Hard mode** — wyzwanie dla doświadczonych

## 📊 Tryby trudności

- **Easy** — 0.6x zombie
- **Normal** — 1.0x zombie
- **Hard** — 1.5x zombie + więcej
- **Leaderboard** — Best Kills (zapisywane w przeglądarce)

## 🏠 Powrót

- Wciśnij **ESC** lub **H** — powrót do menu głównego
